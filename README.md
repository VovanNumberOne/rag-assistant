# 🤖 RAG-ассистент с Telegram-ботом

Полноценный RAG-ассистент (Retrieval-Augmented Generation) с интерфейсом в виде Telegram-бота.
Система отвечает на вопросы по вашей базе знаний: находит релевантные фрагменты документов
через векторный поиск и генерирует точный ответ через OpenAI API.

---

## 📌 О проекте

Проект реализует классическую RAG-архитектуру:

1. Пользователь задаёт вопрос в Telegram.
2. Система ищет релевантные фрагменты в векторной базе (ChromaDB).
3. Найденный контекст + история диалога передаются в LLM (OpenAI).
4. Сгенерированный ответ отправляется пользователю и сохраняется в кеш (SQLite).

```text
Вопрос (Telegram)
      ↓
Telegram-бот (telebot)
      ↓
RAGService (сервисный слой)
      ↓
RAGPipeline
      ↓
Кеш (SQLite) ──► ответ из кеша (если вопрос уже задавали)
      ↓ (если в кеше нет)
Векторный поиск (ChromaDB + OpenAI Embeddings)
      ↓
Промпт с контекстом и историей диалога
      ↓
Генерация ответа (OpenAI API, gpt-4o-mini)
      ↓
Сохранение в кеш → ответ пользователю
```

---

## 🚀 Возможности

- **RAG-архитектура** — ответы строго на основе загруженной базы знаний.
- **Telegram-интерфейс** — общение с ассистентом через привычный мессенджер.
- **История диалога** — бот помнит контекст последних 6 сообщений (3 вопроса + 3 ответа).
- **Умный кеш** — SQLite хранит пары «вопрос–ответ», повторяющиеся вопросы не тратят токены API.
- **Массовая загрузка знаний** — автоматически индексируются все файлы `.txt` и `.md` из папки `data/`.
- **Команды бота** — `/start`, `/help`, `/stats`, `/reset`, `/clear_cache`.
- **Логирование** — все запросы, ответы и ошибки пишутся в `logs/bot.log`.
- **Обработка ошибок** — бот не падает при сбоях API, длинные ответы разбиваются на части.
- **Оценка качества** — отдельный скрипт оценки точности системы через RAGAS.
- **Консольный режим** — можно общаться с ассистентом без Telegram через `app.py`.

## ⚙️ Установка

### 1. Требования

- Python 3.10+
- Аккаунт OpenAI с API-ключом
- Telegram-бот, созданный через `@BotFather` (нужен токен)

```bash

```


## 🔑 Настройка окружения

Скопируйте шаблон `.env.example` в `.env` и заполните своими ключами:

```bash
copy .env.example .env       # Windows
cp .env.example .env         # Linux / macOS
```

Содержимое `.env`:

```env
# Секреты
OPENAI_API_KEY=sk-...
TELEGRAM_BOT_TOKEN=123456789:ABC-DEF...

# Настройки модели и коллекции

# Пути
DATA_DIR=data
CACHE_DB_PATH=rag_cache.db
```

> ⚠️ Файл `.env` содержит секреты и **никогда не должен попадать в Git**.
> Он добавлен в `.gitignore`. В репозиторий коммитится только `.env.example`.

Получение ключей:

- **OpenAI API Key** — https://platform.openai.com/api-keys
- **Telegram Bot Token** — создать бота у `@BotFather` и получить токен.

## 📚 Подготовка базы знаний

Положите ваши текстовые файлы в папку `data/`:

```text
data/
├── article1.txt
├── lecture_notes.md
└── faq.txt
```

Поддерживаемые форматы: `.txt`, `.md` (кодировка UTF-8).

При первом запуске система:

1. прочитает все файлы из папки `data/`;
2. разобьёт текст на смысловые чанки с перекрытием (overlap);
3. создаст эмбеддинги через OpenAI API;
4. сохранит их в ChromaDB.

> 💡 Первый запуск может занять минуту и потратить немного токенов на эмбеддинги.
> Повторные запуски используют уже готовую базу — переиндексация не происходит.

## ▶️ Запуск

Все команды выполняются **из корня проекта**.

### Telegram-бот (основной режим)

```bash
python -m bot.main
```

Ожидаемый вывод:

```text
INFO | bot.main | Проверка конфигурации...
INFO | bot.main | Инициализация RAGService...
INFO | bot.main | Telegram bot запущен. Ожидание сообщений...
```

После этого откройте вашего бота в Telegram и отправьте `/start`.

### Консольное приложение (CLI)


Внутри консоли доступны команды: `stats` — статистика, `clear` — очистка кеша, `exit` — выход.

```bash

```

Покажет пути, наличие `.env`, ключей и файлов базы знаний без запуска бота.

### Оценка качества (RAGAS)

```bash

```

## 💾 Как работает кеш

- Каждый успешный ответ сохраняется в SQLite (`rag_cache.db`).
- Ключ — SHA-256 хеш нормализованного вопроса (регистр и лишние пробелы не важны).
- Повторный вопрос мгновенно возвращается из кеша с пометкой `💾 Кеш`.
- Очистка кеша: команда `/clear_cache` в боте или `clear` в CLI.

## 📝 Логирование

- Бот пишет логи в файл `logs/bot.log` и дублирует их в консоль.
- Уровень логирования настраивается переменной `LOG_LEVEL` (`DEBUG`, `INFO`, `WARNING`, `ERROR`).
- В логах фиксируются: вопросы пользователей, источник ответа (кеш/API), время ответа и ошибки.

Пример записи:

```text
2026-08-07 14:32:10 | INFO | bot.handlers | user_id=123456789 question=Что такое RAG?
2026-08-07 14:32:13 | INFO | bot.handlers | user_id=123456789 answer_sent=True from_cache=False duration=3.21
```

## 📊 Оценка качества (RAGAS)

Скрипт `evaluate_ragas.py` прогоняет набор тестовых вопросов через RAG-систему
и вычисляет метрики качества:

- **Faithfulness** — насколько ответ опирается на найденный контекст (0.0–1.0).
- **Context Precision** — насколько найденный контекст релевантен вопросу (0.0–1.0).

Запуск:

```bash
python evaluate_ragas.py
```

Пример вывода:

```text
[МЕТРИКИ] Средние значения:
   Faithfulness (точность ответа):          0.8500
   Context Precision (точность контекста):  0.7800
[ИТОГО] Средний балл: 0.8150
   Оценка: Отличное качество! [OK]
```

> ⚠️ Оценка использует OpenAI API как для генерации ответов, так и для работы
> метрик RAGAS, поэтому запуск расходует токены и занимает 1–2 минуты.

## 🧯 Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| `❌ OPENAI_API_KEY не установлен` | Заполните `.env` (см. раздел «Настройка окружения») |
| `❌ TELEGRAM_BOT_TOKEN не установлен` | Получите токен у `@BotFather` и добавьте в `.env` |
| `В папке data не найдены файлы` | Положите в `data/` файлы `.txt` или `.md` в кодировке UTF-8 |
| `pip install` падает с `ReadTimeoutError` | Используйте зеркало PyPI (см. раздел «Установка») |
| Telegram сбрасывает подключение | Бот использует `infinity_polling` и переподключается автоматически |
| Бот не видит новые файлы в `data/` | База индексируется один раз. Для переиндексации удалите папку `chroma_db/` |
